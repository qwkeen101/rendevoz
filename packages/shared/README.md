# @rendevoz/shared

Shared utilities, hooks, types, and components for Rendevoz packages.

## Installation

```bash
npm install @rendevoz/shared
```

## Usage

```typescript
import { /* utilities */ } from '@rendevoz/shared'
import { /* hooks */ } from '@rendevoz/shared/hooks'
import { /* types */ } from '@rendevoz/shared/types'
import { /* components */ } from '@rendevoz/shared/components'
```
